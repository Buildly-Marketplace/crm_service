# ForgeCRM Assets

This directory contains visual assets for ForgeCRM.

## Required Assets

### Logo
- **logo-512.png** - Primary logo at 512x512 pixels
- **logo-256.png** - Optional smaller logo at 256x256 pixels

### Screenshots
- **screenshot-1.png** - Dashboard overview
- **screenshot-2.png** - Account management interface
- **screenshot-3.png** - Sales pipeline view

## Asset Guidelines

### Logo Requirements
- Format: PNG with transparent background
- Size: 512x512 pixels minimum
- Style: Clean, professional, readable at small sizes
- Colors: Should work on light and dark backgrounds

### Screenshot Requirements
- Format: PNG or JPEG
- Size: 1280x720 pixels recommended
- Content: Show key features and functionality
- Quality: High resolution, clear text
- Context: Include realistic sample data

## Creating Assets

### Logo Creation
1. Design a logo representing CRM/business automation
2. Include "ForgeCRM" text or make it recognizable
3. Export as PNG with transparency
4. Test at various sizes (32px to 512px)

### Screenshot Capture
1. Run ForgeCRM with sample data loaded
2. Navigate to key screens (dashboard, accounts, opportunities)
3. Capture at 1280x720 or higher resolution
4. Crop and optimize for web display

## File Naming Convention

- `logo-512.png` - Primary logo
- `logo-256.png` - Alternative size
- `logo-icon.png` - Icon version (64x64)
- `screenshot-dashboard.png` - Main dashboard
- `screenshot-accounts.png` - Account management
- `screenshot-pipeline.png` - Sales pipeline
