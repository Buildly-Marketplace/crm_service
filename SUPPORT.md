# ForgeCRM Support

## Support Scope

Buildly Labs provides **30-day installation and configuration support** for ForgeCRM, covering:

### Included Support

✅ **Installation Issues**
- Docker container setup and troubleshooting
- Kubernetes Helm chart deployment assistance
- Database connection and migration problems
- Environment variable configuration
- Port and networking configuration

✅ **Configuration Support**
- Initial setup and first-run assistance
- Authentication and security setup
- PostgreSQL database setup and extensions
- API endpoint testing and validation
- Basic usage guidance for core CRM features

✅ **Documentation Clarification**
- Explanation of setup procedures
- API usage examples and troubleshooting
- Configuration parameter guidance

### Not Included

❌ Custom feature development  
❌ Business logic modifications  
❌ Performance optimization for specific use cases  
❌ Third-party integration development  
❌ Production infrastructure design  
❌ Data migration from other CRM systems  
❌ Custom reporting or dashboard development  

## Support Timeline

- **Response Goal:** 48 hours for installation and configuration issues
- **Support Window:** 30 days from first installation attempt
- **Hours:** Business hours (Monday-Friday, 9 AM - 5 PM UTC)

## How to Get Support

### For Buildly Labs Customers

1. **Labs Portal:** Access support through your Buildly Labs project dashboard
2. **Email:** Send detailed issue descriptions to labs-support@buildly.io
3. **Include:** 
   - ForgeCRM version
   - Deployment target (Docker/K8s)
   - Error messages and logs
   - Steps to reproduce the issue

### For Forge Marketplace Customers

1. **Forge Support:** Access through Buildly Forge marketplace support channel
2. **Ticket System:** Create detailed support tickets with issue descriptions
3. **Priority:** Paid marketplace customers receive priority response

### Community Support

- **GitHub Issues:** For bug reports and feature requests
- **Documentation:** Check `devdocs/` for common solutions
- **Community Forum:** Buildly community discussions

## Escalation

If you don't receive a response within the stated timeline:

1. **Labs Customers:** Contact your assigned Labs representative
2. **Forge Customers:** Use the escalation option in the Forge support portal
3. **Community:** Tag issues as "priority" in GitHub
